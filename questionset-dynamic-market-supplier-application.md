# Dynamic Market for Services — Supplier Application Question Set

**Source:** ProcurePublic / Peabody Trust Dynamic Market for Services (Notice 2026/S 000-108170, OCID ocds-h6vhtk-07bc12). Extracted from the live application form (7 pages).

**Purpose:** a complete, ordered set of every question a supplier answers to join the Dynamic Market, with answer type, limits and conditional logic, so answers can be drafted offline and reused.

## How to use

- Answer stubs (`>`) sit under each question. Questions marked *Shown if* only appear on the live form when the condition is met.
- Word limits are enforced by the form counter, which counts bullets and line breaks, so leave headroom.
- Pass/fail scoring: technical questions need a score of 3 or more. Weightings apply only at call-off stage.
- Main contact email must not be Hotmail, Gmail or Yahoo. Referee emails must be unique and not Hotmail or Gmail.
- Save at the end of every page. After submitting, you have one hour to amend.
- Two lot variants exist in the form (Lot 1 / Lot 2 wording on Q30, Q34, Q35). The form shows the variant matching the selected workstream.
